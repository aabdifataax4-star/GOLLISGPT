Welcome to the **GOLLISGPT**, an advanced AI chat interface designed to assist users with general knowledge, ICT, health, geography, history, and more. This project serves as a comprehensive system built with offline code libraries, dynamic components, and a bilingual interface (Somali/English).

## 🛠️ How to run the website

This complete folder has everything you need to run the system natively. You do not need any backend setup or local servers to view the UI.

1. **Download the Folder**: Ensure you have this entire folder downloaded, which includes all the files (`index.html`, `style.css`, `script.js`, `check.py`, and the images).
2. **Open the Application**: 
   - Navigate into the **GOLLISGPT** folder.
   - Simply double-click on the `index.html` file, or right-click and open it with **Google Chrome** (or your favorite modern browser like Edge, Firefox, or Safari).
3. **Usage**:
   - Use the main chat to type your questions.
   - Explore the left sidebar options like **Plugins**, **Code Library**, and **Images**.
   - Test out the modals and UI functionality.
